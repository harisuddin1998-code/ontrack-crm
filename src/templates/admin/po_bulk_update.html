How the file should look

A header row, then one row per purchase order. Word files are read from the first table in the document.

{# Four rules, each its own block. Set as a paragraph they read as background text; the one that matters most - a blank cell never erases anything - has to be impossible to skim past. #}
Identify each order

One column must be PO Number (matched exactly) or Reg No.

Empty cells are left alone

A blank never erases a value that is already recorded, and no column below is required — bring whichever ones your sheet has.

Updated orders reach the installers

Any order still PENDING or IN_PROGRESS after the update is routed to the installation team.

Status must be a known one

PENDING, IN_PROGRESS, COMPLETED or CANCELLED.

Completing a PO is not just a status

It does everything completing it on the form does — sends the completion email and raises the security briefing.
